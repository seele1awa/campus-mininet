Addressing And VLAN

地址规划与 VLAN 分区

学生宿舍VLAN 1010.10.10.0/24
教学楼VLAN 2010.10.20.0/24
图书馆VLAN 3010.10.30.0/24
办公楼VLAN 4010.10.40.0/24
人事处VLAN 5010.10.50.0/24
财务处VLAN 6010.10.60.0/24
访客网络VLAN 7010.10.70.0/24
服务器区VLAN 10010.10.100.0/24
外部模拟区VLAN 200203.0.113.0/24

设计思路

`10.10.X.0/24` 让区域边界直观清晰。

VLAN 隔离广播域，减少二层范围扩散。

保留后续网段，便于扩展无线、实验室和新服务区。

Network Principles

网络原理：从 VLAN 到三层转发

Access

主机接入端口

OVS 端口打上单一 VLAN tag，区域内保持二层交换。

Trunk

上联汇聚

接入交换到 `s_core`，`s_core` 到 `r_core` 承载多 VLAN。

Router

单臂路由

`r_core-eth0.<vlan>` 作为各 VLAN 网关。

Forward

Linux IPv4 转发

开启 `net.ipv4.ip_forward`，完成跨区域通信。

真实实现位置：`src/campus_net.py` 中 `configure_vlans()`、`LinuxRouter`、`configure_security()`。

Security

安全策略：核心 ACL 与审计记录

外部边界：`203.0.113.0/24` 禁止进入校园内网。

敏感保护：学生、教学、图书馆不能访问人事和财务。

业务放行：办公楼允许访问人事处与财务处。

访客隔离：访客只允许访问服务器区 Web/FTP。

Services

服务与动态网络：Web / FTP / DHCP / DNS

服务器区

`web`：10.10.100.10，HTTP 80

Live Console

Multi-Campus VPN

四校区通信：GRE VPN 隧道模型

宝山主校区 保留完整校园网，作为 VPN Hub。

嘉定、延长、东京 使用极简 LAN 示意，降低复杂度。

GRE/IP tunnel 模拟跨校区 VPN，支持真实 ping / Web / FTP。

东京链路 设置更高时延，体现跨国访问差异。

Operations Console
